# Microsoft 365 Troubleshooting

This repository contains Microsoft 365 and Entra ID troubleshooting documentation created for IT support, MSP, and help desk workflows.

The purpose of this repository is to document practical troubleshooting steps for common Microsoft 365 issues involving user access, MFA, Outlook, Teams, licensing, shared mailboxes, and administrative workflows.

## Documentation Included

| Guide                             | Purpose                                                                                                 |
| --------------------------------- | ------------------------------------------------------------------------------------------------------- |
| mfa-troubleshooting-workflow.md   | Step-by-step workflow for troubleshooting MFA registration, sign-in prompts, and authentication issues. |
| entra-id-admin-consent.md         | Guide for resolving application admin consent issues in Entra ID.                                       |
| outlook-sign-in-issues.md         | Troubleshooting steps for Outlook login, profile, and mailbox access issues.                            |
| new-user-onboarding-checklist.md  | Checklist for creating and preparing a Microsoft 365 user account.                                      |
| shared-mailbox-troubleshooting.md | Guide for troubleshooting shared mailbox access and permissions.                                        |
| conditional-access-basics.md      | Overview of basic Conditional Access concepts and troubleshooting considerations.                       |
